## Challenge

Publishing to several social networks means repeating the same work in four different tools:
uploading the same video, rewriting the same caption, and collecting numbers from four dashboards.
ViralSync puts the channels of a brand behind one workflow.

## Solution

ViralSync is being built around a shared workspace for brand channels, a media library and a
reviewable publishing workflow. The current build has its organization and brand foundation,
media library and channel connection foundations. Publishing, analytics presentation and the
assistant interface are still being completed. Production controls and provider approvals remain
under release review; this portfolio page is a project case study, not an offer of general availability.

## Architecture & System Design

The platform is designed as a type-safe monorepo separating web frontends, API backends, and domain contracts:

- **Web Application:** Next.js App Router with React Server Components, server actions, and optimistic calendar planning views.
- **Edge API:** Lightweight Hono framework deployed to Cloudflare Workers for fast multi-region request routing and low edge latency.
- **Data Persistence:** Neon Serverless PostgreSQL with connection pooling, migrations managed via Drizzle ORM, and schema validation with Zod.
- **Provider Adapters:** Every external social network (Instagram, TikTok, YouTube, LinkedIn) is encapsulated behind a strict provider interface with its own configuration manifest.

## Engineering Decisions & Quality Gates

1. **Shared Domain Logic:** Domain entities, validation rules, and business logic are isolated in independent workspace packages. The web application and edge API share identical invariants without code duplication.
2. **Automated Testing with Mock Providers:** In integration test suites, a simulated mock provider validates the entire publishing and scheduling flow without consuming external API rate limits or requiring third-party credentials.
3. **Status & Delivery Boundaries:** 
   - *Implemented & Verified:* Multi-brand organization hierarchy, media library storage, and mock-adapter scheduling pipelines.
   - *Planned Beta:* Live social platform OAuth approvals, multi-network publishing queue, and AI assistance interface.
