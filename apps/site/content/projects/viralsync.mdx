## Challenge

Publishing to several social networks means repeating the same work in four different tools:
uploading the same video, rewriting the same caption, and collecting numbers from four dashboards.
ViralSync puts the channels of a brand behind one workflow.

## Solution

Accounts on YouTube, TikTok, Instagram and Facebook are connected once. Finished media lives in
a library, posts are planned and published from there, and their analytics come back to the same
place. Every action is available three ways: in the web app, through an AI agent, and through
the API.

## Architecture

The product is a monorepo with a Next.js web app and an API that runs as a Cloudflare Worker.
Domain rules, application use cases, database access and the agent are separate packages, so
the web app, the API and the agent share one implementation of each rule. Marketing site and
user documentation are static sites of their own.
